# AGENTS.md

## Project Overview

**Aruco** is a simple step count app for iOS with Apple Health integration.

## Technology Stack

- **Language**: Swift
- **UI Framework**: SwiftUI
- **Build System**: Xcode project + Swift Package Manager

## Project Structure

- `iOSApp/`: iOS app
- `iOSAppTests/`: Unit tests for iOS app
- `iOSAppUITests/`: UI tests for iOS app
- `Packages/Core/`: Shared logic
